# car-accident-reporting-hcd - Project structure

code/: folder containing the source code of the web application

  index.html: main application structure and screens
  css/style.css: styles, color palette, and visual rules
  js/app.js: interactive application logic
  assets/: graphic assets, car icons (car-a, car-b), maps, and companion guide illustrations (guy)

brainstormm.pdf: notes from research, understanding the task, thoughts, as-is situation analysis, pain points, and transformation pillars

figma-links.txt: links to figma files (user flow, map, and screen wireframes)

personaema.png: user persona visual (driver ema)

personafilip.png: insurance claims adjuster persona visual (filip)


USAGE OF AI
I used AI in this project for brainstorming, structuring my thoughts and research findings into a readable format, problem-solving during the discover and design phase, and providing HTML coding assistance.
